Demos: what to keep

A round on the site lives in its decoded file (data/rounds): the map, the stats, the hints, the player pages. Its demo, 4-5 times bigger, is needed only to decode it again when the decoder changes and for a clip for the game. Old demos can go - their rounds stay and open as before.

Hints over all rounds (bf2replay-hints): every round opened in the site's page on the server, a few at a time, for the players' hint cards; and the grids of where soldiers stood, for Glitch spot. 40 rounds a run, one at a time, 5 minutes after the last run (or all of them at once: "All rounds now"). Posts about new rounds

    
Each game server its own: its new rounds go only to its own Discord channel and / or Telegram chat, with the parts picked for it - the map, who won and the link (the chat shows the map under it) always. A server not set up here is not posted. Rounds downloaded in a batch (recorded more than 12 h before) and clips are not posted.

Servers

    

    
Where to get these
Discord: the channel's settings (the gear) → Integrations → Webhooks → New Webhook → Copy Webhook URL. A channel a server: a webhook each.
Telegram: write to @BotFather, /newbot, copy the token it gives (one bot is enough for every server); add the bot to each group (or as an admin of each channel). The chat: @channelname for a public channel; for a group, its id - send a message in it, open https://api.telegram.org/bot<token>/getUpdates and take "chat":{"id": -100…}.
A server is known by the name in its demos: if its admins rename it, the new name shows here as a new server, not posted until set up.
Kept on the VPS only (data/.notify.json, which the web server never serves); here only the last 4 characters of the secrets show. In /etc/bf2replay.conf BF2R_TELEGRAM_TOKEN and BF2R_NOTIFY_MIN_PLAYERS win over these.

  


  

    
Servers' admins

    
Accounts for the admins of the game servers: each logs in on a round's Admin tab on the site (his name and password) and sees the hints of his servers' rounds there - nothing of this page. You log in there with an empty name and this page's password, and see every server's.
