Demos: what to keep

A round on the site lives in its decoded file (data/rounds): the map, the stats, the hints, the player pages. Its demo, 4-5 times bigger, is needed only to decode it again when the decoder changes and for a clip for the game. Old demos can go - their rounds stay and open as before.

Where to get these
Discord: the channel's settings (the gear) → Integrations → Webhooks → New Webhook → Copy Webhook URL.
Telegram: write to @BotFather, /newbot, copy the token it gives; add the bot to your group (or as an admin of your channel). The chat: @channelname for a public channel; for a group, its id - send a message in it, open https://api.telegram.org/bot<token>/getUpdates and take "chat":{"id": -100…}.
Kept on the VPS only (data/.notify.json, which the web server never serves); here only the last 4 characters show. In /etc/bf2replay.conf BF2R_DISCORD_WEBHOOK, BF2R_TELEGRAM_TOKEN, BF2R_TELEGRAM_CHAT and BF2R_NOTIFY_MIN_PLAYERS win over these.
