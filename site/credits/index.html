From the game's own files

To look like the game and to show what each player could see, the site uses these, taken from Battlefield 2's files:

  • the map pictures (the game's minimaps) and the minimap symbols;
  • the icons of weapons, vehicles, kits and ranks, the sides' flags, the textures of the Tab scoreboard and the top bar, and the game's bitmap fonts;
  • the vehicles drawn from above, made from the game's models;
  • the ground's heights, the shapes of buildings and objects, and the trees, for "who could see whom";
  • names and figures: maps, flags, weapons, vehicles and kits, speeds, ranges and the fog of each map.

The rounds themselves are the game servers' own Battle Recorder demos (.bf2demo), taken from the pages where the servers publish them and read by the site's own decoder.

Read to understand the game — no code taken

These helped to understand how the game works. The site took no code from them: only how things work and the figures, each checked against recorded rounds.

  • OpenBF2 (GPL-3.0): the camera and field of view, soldiers' speeds, scoring, spawning, the combat area, latency compensation.
  • OpenBattlefield2 (MIT): the fog, the soldier's physics, the rules of Conquest, the layout of some records.
  • Refractor-2-BitStream-Emulator (GPL-3.0): the network messages.
  • The game's own scripts and settings (such as gpm_cq.py and the levels' .con files): the rules of the game mode.
